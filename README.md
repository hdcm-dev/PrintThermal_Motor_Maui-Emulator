# PrintThemal-Emulator

Emulador de una impresora térmica Bluetooth ESC/POS de 58 mm (58HB6) para pruebas locales, en contenedor y de extremo a extremo con el emulador de Android. La salida prevista es una imagen del ticket. Tecnología prevista: .NET 10.

**Estado:** idea inicial. Todavía no hay código.

Documentación: [PrintThemal-Emulator.Documentacion](https://github.com/hdcm-dev/PrintThemal-Emulator.Documentacion).
